# Safeguard in the opening

Chikorita learns Safeguard at level 43, reachable through Tiny Woods retries.
The handler, targeting, media and audio use comparative
[Red source at 013475aa](https://github.com/pret/pmd-red/tree/013475aa04f5be3191e5527c186d9bfceae7cae0).
They do not establish Blue cartridge identity or physical audio output.

Actual targeting is room allies (`0x31`), with the user last. Confusion can
expand the selected recipients to the bounded twelve-actor population. Each
recipient retains its ordinary accuracy draw. Fresh application replaces the
shared Reflect-class status and stores 16–20 opportunities; duplicates neither
draw a duration nor refresh it. Existing negative conditions remain. Saves
accept Safeguard on any valid recipient, without inferring the caster from its
species. Native duplicate handling synchronizes icon flags; the browser's
unchanged status needs no new snapshot or bitmap receipt.

Safeguard checks belong to individual status helpers. Sleep and Whiffer draw
their duration before the guard; Leech Seed rejects self-targeting first.
Damaging secondary effects retain damage, chance and Shield Dust handling.
Contact reaction flags sampled during damage still activate afterward, and the
reaction's status helper checks its own recipient. Swagger's Attack increase
continues when confusion is blocked. Ordinary stat drops are unaffected.

The partner AI uses separate room-enemy intent (`0x30`). When every enabled move
has a represented no-foe resolver, Safeguard remains in the opportunity pool
without a visible foe. Other loadouts retain the existing broader AI limitation.
Once selected, it falls back
to a regular attack if no eligible target exists, without a target draw. An
eligible target preserves the original facing and consumes the bound-one draw.
This covers the retained roster's default IQ and ordinary visible actors.

One visible cast owns existing SE2 sound 356 and effect 238 (34 native ticks),
whose first visible creation requests SE5 sequence 776 once. Recipient fanout
does not duplicate either sound. The status uses red shield bit 9/palette 4.
Sequence 776 has three notes through source tick 72; wave 125 contains 17,648
literal bytes with no interpolation guard and decodes to 70,592 Float32 bytes.
Existing voice limits can reject competing requests.
