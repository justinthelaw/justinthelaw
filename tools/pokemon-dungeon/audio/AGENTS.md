# Effect audio inputs

- These JSON catalogs feed offline exporters in `../scripts/`; generated
  `audio-*-data.js` and the authored bank belong to the game runtime.
- Preserve source revisions/hashes, finite note/control facts, sample bounds,
  dynamic voice limits and explicit comparative-Red qualifications.
- Background music is intentionally absent. Do not restore score scheduling
  while changing UI/gameplay effects.
- Validate bytes/exports statically; never execute game/native modules.
  Source routing does not prove Blue driver/waveform identity or physical sound.
- [Audio evidence](../reference/blue-audio.md) owns current cue/transport limits.
