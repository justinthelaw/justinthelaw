## Concrete interfaces

```javascript
sinisterSelfStatus(context, actor, status, source, turns, catalogs); // void
cureSinisterStatuses(context, actor, catalogs); // void
```

The arguments use the existing `MutationContext`, `SessionActor`, `EffectSource`
and gameplay `Catalogs`. The context is the real detached private draft plus its
concrete `emit`, never a projected session or a callback that promises mutation.
The returned functions do not sample Effect Spore chance/selector, issue its
scatter message, invoke display, advance native work, learn moves, move actors,
settle loss, change floors, create actors or admit a save.

## Shared all-cure order

The exact negative predicate is the unchanged native-sourced
`hasNegativeStatus`. If it is false, beneficial class states survive. If true,
the source order is Sleep(FALSE,FALSE), validity guard, Burn, Frozen/reciprocal
Wrap, Cringe plus speed refresh, Curse(0), Leech Seed, sureShot, eyesight, Muzzled,
Perish Song, Exposed. Source class-end messages precede clearing ordinary class
fields; Perish/Exposed clear before their messages. Condition invalidations are
browser notifications, not copied native animation/frame instructions.

The negative predicate can be true solely because of a seal or slow counter.
Even then beneficial Sleepless/Napping, Ingrain, Focus Energy/Sure Shot and
Eyedrops are ended by those real class-end calls. Reflect/Protect/Bide, invisible,
Long Toss, positive speed timers, stat stages/multipliers, Grudge, HP maxima,
move PP, source/move flags and every scheduling flag stay intact.

Napping emits its end, heals up to999 through the represented current maxHP
(with the authentic positive HP outcome message), clears sleep, then invokes one
recursive cure. Sleep is already empty, so it cannot recur again. The outer
owner then resumes its validity guard and remaining class calls; already-cleared
classes emit nothing twice. FALSE,FALSE causes neither Nightmare damage nor a
Yawn-to-Sleep transition, and no cure duration/chance draw occurs.

After the class section, calculate the speed cache, clear all five negative
speed counters, recalculate it and message only a real stage change. Existing
move battle slots alone are unsealed, preserving each slot's PP and all other
flags. Unsealing has one shared outcome message. A valid already-healthy actor
receives the source no-effect message. No generic floor/reset/heal shortcut is
used and no scheduler flag is reset or new opportunity installed.

## Finite notification and draw ceilings

Let `N=132` live actors and `D=8` neighboring directions. `C` is an actual
`conditionChanged` event and `K` is an actual `message` event. One para/poison
chain has at most `N` successful replacements, since it writes before recursion.
Each success can attempt at most8 recursive recipients; total calls are bounded
by `1+8N=1057`. Each call emits at most one guard/success `K`, plus at most one
Synchronize `K` per successful actor. No recursive call scans retired actors.

| Leaf unit | C ceiling | K ceiling | Total | Additional browser draws |
| --- | ---: | ---: | ---: | ---: |
| One paralysis chain | 132 | 1189 | 1321 | 132 upper1 duration draws |
| One poison chain | 132 | 1189 | 1321 | 0 |
| One supplied sleep application | 1 | 1 | 2 | 0; its prior caller draw is charged separately |
| One all-cure recipient | 14+1 reciprocal | 14 | 29 | 0 |
| All132 recipients, if a caller loops without yielding | 1980 | 1848 | 3828 | 0 |

All-cure's recipient bound includes eleven ended class/auxiliary fields, one
Napping HP change, slow-counter removal and seal removal (`14C`), plus at most
one reciprocal partner invalidation (`1C`). It includes eleven class messages,
one Napping HP message, one speed-change and one unseal message (`14K`). Napping's
nested invocation clears each field once, not a second whole all-cure budget.
With `q` actual cures and `r` touched reciprocal endpoints, the stronger bound
is `C<=14q+r`, `K<=14q`, `r<=q`. Each recipient owns at most one such endpoint,
even when the retained counterpart is retired; record count creates no fanout.
This bound requires the caller's real reciprocity and retirement obligations.

The leaf limits exclude outer scatter/chance/selector, shared move damage,
other contact reactions, display, Bide, growth, faint/Reviver, entry and terminal
cleanup events. Two Spore class chains cannot be hidden under one1321 allowance.
The selected caller must account for every actual chain in its bounded chunk.
