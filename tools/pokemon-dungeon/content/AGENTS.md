# Selected factual catalogs

- `blue-source.json` retains selected source records and historical donor hashes.
  Its full hero growth/learnsets are required because retries preserve EXP.
- `blue-onboarding/` keeps the complete quiz/partner evidence; only four playable
  projections ship. `sources.json` stays offline.
- Wild spawn facts, secondary gates and `rule-runtime/` type matchups are
  independent evidence, not outputs inferred from the browser implementation.
- Use the owning exporters in `../scripts/`; do not hand-edit generated game
  content. Source corrections require independent review and deliberate digest
  updates in `check-blue-facts.mjs`, never automatic repinning.
- Preserve edition/revision/URL/hash qualifications. Refer to
  [factual checks](../reference/blue-facts.md) for projection boundaries.
