# Private fresh-run construction prefix

`createSinisterConstruction(predecessor, catalogs, authority)` now composes the
actual admitted v24 MAIN5,9 predecessor, source roster address mapping, new-run
preseed and conversion Hidden Power, native slot zeroing and whole-Dungeon
geometry zeroes into one private owner. Callers supply the real Adventure
transaction authority; the owner derives every prerequisite receipt itself.
It neither accepts a fabricated memory journal nor repairs an old session.

`getSnapshot()` returns the deeply frozen current result. Its exact object
identity is the continuation token for `beginFirstFloor(snapshot)`. A JSON copy,
stale token, repeated call, or disposed owner cannot continue. The first-floor
operation derives and consumes an actual canonical map ID, advances the actual
native preseed, invokes the reviewed slot reset owner, and records all of these
results before atomically swapping the private snapshot. Failure leaves the
prior snapshot untouched. The complete predecessor uses its established plain
data budget independently of the small authority envelope.

This is a usable construction prefix, not complete v25 raw admission or a live
departure. It deliberately ends at `floor-prefix-ready`. The existing native
slot reset combines a projection of source writes separated by other native
operations; this new journal records that projection and does not pretend it
has executed a contiguous native PC. It performs no browser RNG reseed, Deoxys
draw, cache/layout generation, geometry reset, placement, temporary Hidden
Power, initial AI, final party copies, sleep, final refresh, actor allocation
or canonical snapshot mutation.

Whole-Dungeon geometry is zeroed once at this authenticated fresh RunDungeon
boundary. Actual room bytes start0; ResetTile changes them to255 later. The
first-floor preparation retains those bytes, the32 room records and all32
junction tail positions per room. No final layout is guessed from current
actors. Geometry operation implementations remain byte-identical to the prior
reviewed checkpoint.

The next owner must produce the source-ordered floor RNG/cache/layout history
and temporary actor initialization before executing initial AI. In particular,
InitEntityFromSpawnInfo first resets statuses/abilities, writes placement,
level/behavior and IQ, then samples a separate temporary Hidden Power. The
already-retained roster conversion draw cannot substitute for this later
sample. Connecting only allocation to Hidden Power would omit real source
history, so that shortcut remains unavailable.

All ten existing runtime dependencies are unchanged and pinned. Four inherited
audits gain only the exact named constructor/typedef consumers; the new audit
reconstructs and authenticates their complete prior bytes. Source/AST and nine
negative controls are in `check-sinister-construction.mjs --native-root
/path/to/pinned-native`. No game/native code executes. Independent review and
strict static checks remain required before widening the producer. This
unselected journal has no serialization/import route and does not change
historical saves, selected gameplay, the4096 event cap or release acceptance.
