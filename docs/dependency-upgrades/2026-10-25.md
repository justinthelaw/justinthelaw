## Graph and deferral review

The complete root npm lock's 397 package names and both Python locks' 84 package
names were compared with official registries. Native npm resolution changes 44
package versions, including coherent optional Next/SWC and lint families; no
packages were added or removed. Native uv resolution changes four package
versions in each Python lock. A second CI-style compile reproduced both locks.

Retain parent-owned Babel 7, nanoid 3 and protobufjs 7 despite newer majors:
this change preserves the maintained compatibility/security overrides rather
than forcing unsupported major dependencies. The browser ONNX prerelease
`1.31.0-dev.20260914-8d85527a0` remains deliberate and is not downgraded to the
stable 1.30.0 tag. GPU libraries remain pinned by the Torch graph. Newer optional
transitive releases outside the selected update families were reviewed but are
not a reason for a wholesale lock refresh or leaf overrides.

The earlier unavailable-archive deferrals for PostCSS, ESLint React, Markdown,
Transformers and HTTP packages are superseded by successful native installs.
The npm CLI and downloaded GitHub Action bundles remain separate dependency
owners; their known upstream security deferrals remain documented in
[Development](../DEVELOPMENT.md#dependency-decisions). A clean application audit
does not certify these external tool bundles. No deployed model or site changes.
