# Dependency audit records

Dated Markdown and adjacent CSVs are historical evidence, not live dependency
policy. Current pins belong in manifests, lockfiles, runtime files and workflows.
Keep summaries short; retain every ledger row, version, outcome, hash and source
URL. Preserve old paths in historical CSVs and label their snapshot date. Link
superseded decisions to later audits and current source; never present recorded
checks or pending PR gates as fresh validation.
