## Provenance and decisions

At discovery, no PRs were open. [#379](https://github.com/justinthelaw/justinthelaw/pull/379)
had incorporated the already-closed #376-378; the audit used a fresh branch.
Official registries, release tags, schedules and dependency contracts were checked
on September 29. Native resolution retained owning contracts and bundled leaves.

- Website TypeScript 7.0.2 was outside parser peers `>=4.8.4 <6.1.0`;
  TypeScript 6.0.3 and Node 24.21.0 were retained. Node 26 was deferred to LTS.
- Transformers 5.17, tokenizers 0.23.2 and datasets 5.0.1 excluded Hub 2.0.0;
  both Python lanes retained 1.33.0. This deferral is superseded by
  [October 12](2026-10-12.md).
- filelock 4's change concerned soft read/write locks; classic FileLock/SoftFileLock
  passed a real smoke test and the full suite.
- urllib3 2.8.0 addressed the recorded
  [proxy TLS](https://github.com/urllib3/urllib3/security/advisories/GHSA-8988-9cw3-xx77),
  [chunk-memory](https://github.com/urllib3/urllib3/security/advisories/GHSA-vxq7-64xx-v4gw)
  and [Deflate-loop](https://github.com/urllib3/urllib3/security/advisories/GHSA-gh4c-6fx4-qh6g)
  advisories.
- texthooks 0.7.1 replaced deprecated fix-smartquotes with the same hook/stages.
  Byte and exit-code comparisons covered Markdown, ASCII, CRLF without EOF,
  Unicode quotes and custom arguments.
- PostCSS `^3.3.18` and ONNX `^7.2.4` contracts excluded Nano ID 6/protobufjs 8;
  Nano ID 3.3.19 was selected. Tailwind retained its six bundled WASM helpers.
- [npm #9800](https://github.com/npm/cli/issues/9800) rejected lock-only updates
  and pruned those optional records during actual updates. Unchanged authoritative
  records were restored before native regeneration. Installed-tree checks had
  missed the incomplete lock graph, motivating `npm ls --all --package-lock-only`
  after clean installs.
