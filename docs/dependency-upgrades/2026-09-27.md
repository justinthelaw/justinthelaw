## Compatibility and deferred upgrades

- Node 24 is the active runtime; Node 22 remains within supported upstream ecosystem compatibility where relevant, while this repository requires Node `>=24.19.0 <25`. Node 26 and `@types/node` 26 are deferred until the runtime lane is reviewed. [Node release schedule](https://github.com/nodejs/Release#release-schedule).
- TypeScript 6 remains pinned. TypeScript 7 is deferred until typescript-eslint supports it; see [typescript-eslint dependency support](https://typescript-eslint.io/users/dependency-versions/).
- The active ML lane is Hugging Face Hub 1 / Transformers 5. The [August 16 ML lane plan](../superpowers/plans/2026-08-16-ml-lock-dependency-lane.md) is historical and does not specify the current requirements.
- This audit records the current stable versions requested in the task, with independently checked npm metadata for Next.js 16.3.6, baseline-browser-mapping 2.11.26, and @types/node 24.19.0 and Python lock resolution for Hub 1.33.0. Other upstream links identify exact pinned releases; for those entries, no newer stable release independently verified.
