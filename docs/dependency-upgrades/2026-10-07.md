## Provenance and migrations

The October 7 review checked official registry metadata, release tags, schedules
and parent contracts. [#392](https://github.com/justinthelaw/justinthelaw/pull/392)
was explicitly excluded; no other source PRs needed consolidation. The branch
was isolated from the separate game checkout.

- Transformers 5.19 required fractional `warmup_steps`, not `warmup_ratio`;
  5.17 had the same incompatibility. Real constructor regressions for zero, 5%
  and 100% of 200 steps reproduced TypeError, then passed after extraction of
  argument construction. CLI `--warmup-ratio` remained; 100% required an explicit
  positive step budget and mapped to that entire budget. Invalid ratios were tested.
- Website TypeScript 7.0.2 exceeded parser peers `>=4.8.4 <6.1.0`; 6.0.3 remained.
  Game tools separately tried 7.0.2 but retained 6.0.3 because their then-current
  CompilerHost used `ts.sys`, `createCompilerHost` and virtual vendor resolution.
  The later CLI migration retired that game-tool deferral.
- tokenizers 0.23.2 still required Hub `<2`, although Transformers/datasets allowed
  2.1.1. Hub 1.33.0 was retained; the later tokenizers update removed this block.
- Node 26.11.0 was Current with October 28 LTS planned; Node 24.21.0 remained.
  Python 3.15 was not yet final, so 3.14.8 remained.
- Parent contracts retained Nano ID 3.3.20/protobufjs 7.6.6 instead of majors 6/8.
  [npm #9800](https://github.com/npm/cli/issues/9800) required restoring six
  unchanged Tailwind 4.3.3 WASM records before native regeneration; clean install
  and the complete virtual graph passed without relaxing security/script policy.

## Migration and retained constraints

[GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) had no
published braces 3.0.3 patch. The manual publisher chain
`gh-pages -> globby -> fast-glob -> micromatch -> braces` produced five high
npm entries for one advisory. Compatible parents still selected it. The suggested
gh-pages 6.1.1 downgrade returned to globby 6 and unsupported glob 7, losing
publisher fixes including dash-prefixed filenames; current globby was ESM while
gh-pages required CJS. The audit deferred an upstream patch or separately validated
publisher migration. Its security result was not clean.
