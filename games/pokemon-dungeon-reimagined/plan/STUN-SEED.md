## Application and lifetime

T01/T02 retain origin consumption, detached payload ownership, protected direct
targets, accuracy, catch and sticky ordering. A successful throw interrupts
Petrified and ordinary native127 Sleep before catch/effect. Uncaught sticky
payload causes fixed2 and returns; an ordinary seed gives5 Belly before Stun,
including a blocked or duplicate effect. There is no effect-driven refund.

The live current-floor recipient is checked before Safeguard, which also blocks
self ingestion. No boss, Suction Cups, sleep ability or paralysis immunity is
invented. A duplicate Petrified effect neither samples nor refreshes; an actual
new effect replaces the frozen group and records the real item user. Native
Wrap/Wrapped reciprocal release precedes application, but neither status is
admitted by the published policies. A future such state gets the explicit
`stun-reciprocal-wrap-release` dependency, never a one-sided partial cure.

## Interruption and safe swap

`status-interruptions.js` clears Petrified first, then only ordinary Sleep with
native127 (including the existing indefinite spawn representation). Finite Sleep,
Nightmare/Napping and other frozen classes are not a blanket cure. Condition/end
feedback is emitted only for an actual change; repeated calls draw nothing.

| Boundary | Ordering |
| --- | --- |
| Move target preprocessing | Before protection and accuracy |
| Shared damage, including zero | Before HP mutation and existing faint/revival/drop/XP/reaction work |
| Successful thrown impact | After eligible accuracy succeeds; before catch, sticky and item effect |
| Leech/Liquid Ooze residual damage | Shared damage boundary releases its damaged actor; healing does not |
| Safe team swap | Existing special own beginning tick first; flagged AI clears only Petrified before forced counterpart walk |
| Floor transition/revival/Rapid Spin | Existing complete temporary/frozen-class cleanup remains unchanged |

Safe swap permits Petrified without relaxing other immobilization, sleep,
confusion, charging, affiliation or terrain guards. The engine's special pass,
`petrifiedSwap`, `swapSkip` and pending ordering are unchanged. Its begin hook
allows only the actual flagged special-pass Petrified actor to reach AI; no
ordinary Petrified actor gains an action and no extra turn is manufactured.
Repeated deferred AI opportunities that skip begin still pass while Petrified;
the flagged counterpart remains the only exception. The new v18 scheduler
policy also rejects a ready leader decision that still carries Petrified,
because supplied actions at that boundary do not rerun beginning upkeep.
Warp will call the shared interruption after its own sourced guards; no Warp
implementation is included here.
