# Direct escort resource callbacks

This unselected v24 prerequisite owns actual resource callbacks for the complete
successor. It does not select a factory or authorize a second-work outing.
Frozen v23 composite callbacks reject the genuine guest/revision by design;
these callbacks therefore compose their original field primitives directly on
actual state. Every state-owning callback first repeats entry/runtime/lifecycle,
movement history and saved learning proof, then requires the final factory's
complete raw proof callback before any field delegation. Options have no state
argument and retain their original value-only primitive.

| Field | Actual ownership |
| --- | --- |
| Profile/economy/item | Original direct primitives retain all roster, guest held lots, entry archive, money and area resources. |
| Permanent Magnemite | Actual once-only scripted grant and source natural stats at its real current level; ordinary source learning remains valid. No default level6 reset. |
| Actor | Actual wild/fixed/client/roster field owners; escort binding requires source-proved genuine guest. A source-proved pending roster loss only projects the primitive live-HP placement guard. |
| Floor | Raw geometry and exact final ordinary town exit; fixed Steel geometry remains independently checked. Proved special-swap occupancy remains valid during automatic or choice learning pause. |
| Conditions | Existing exact local condition owners; guest Petrified adds genuine current/removed source generation. Proved retired roster slots are available only as condition witnesses, never AI or resources. |
| Scheduler | Actual fresh/input/continuing PCs; saved learning owns its real source frame; ordinary Steel summit retains its actual fresh scene pause including a true guest slot. |
| Entry | Every actual selected roster baseline retains its source nonreset policy, full resources and exact original moves/PP. Guest entry remains separate. Source route capacity stays in raw entry proof. |

No guest is deleted, substituted for a roster member, or assigned an old content
revision to pass a field check. Retired-slot views can copy the session object;
guest source proof resolves the actual canonical session ID and native generation,
not object equality against that condition-only copy. All unrelated condition
classes keep their explicit unresolved owners. Nonempty rescue restoration is
still a separate owner; this package grants no rescue admission.

The required complete proof callback must later own second-work/native history,
station prefix and mission area receipts, old Pidgey coexistence and genuine
scene/result/return relationships. Resource proof alone is deliberately insufficient.
Live factory/envelope conversion, central caller/readiness/UI and MAIN5,7–5,9
history remain next. No new producer/events, bound widening, game execution,
Blue parity or human/device/visual acceptance is claimed.

`escort-resources:check` statically parses the callbacks and checks delegation,
preflight ordering, condition witnesses, casualty/swap and raw final-exit arms.
Source/type and frozen save-boundary audits remain required.
